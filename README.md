# 1-Bit Full Adder

## Project Overview
Design and simulation of a 1-bit Full Adder using Qucs-S.

## Inputs
- A
- B
- Cin (Carry Input)

## Outputs
- Sum
- Carry

## Boolean Expressions
- Sum = A XOR B XOR Cin
- Carry = (A AND B) OR ((A XOR B) AND Cin)

## Tools Used
- Qucs-S 26.1.1
- Digital Logic Gates
- Verilog HDL
